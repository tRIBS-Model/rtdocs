Examples
=====================

Beyond the :doc:`QuickStart` walk-through, several external repositories provide more complete, worked examples
of building, running, calibrating, and post-processing tRIBS models. These are maintained separately from this
documentation and are the recommended starting point for learning pytRIBS or setting up a new watershed.

pytRIBS Examples
~~~~~~~~~~~~~~~~~~~

The `pytRIBS examples <https://github.com/tRIBS-Model/pytRIBS-examples>`_ repository is the reference workflow for learning pytRIBS, building a model of an example completely from watershed from scratch. It covers the updated pytRIBS v1.0.0 input structure, mesh generation, spin-up, and plotting tools. The example is based around the Newman Canyon watershed in Central Arizona with the mjority of the data needed to run the model being downloaded or generated by pytRIBS. The example uses the built-in Docker tools in pytRIBS to run the simulation. The user can go this route by downloading the Docker program or compile tRIBs directly on their computer and run the generated input file manually.

tRIBS Workshop Sandbox
~~~~~~~~~~~~~~~~~~~~~~~~~

The `tRIBS Workshop Sandbox <https://github.com/tRIBS-Model/tRIBS-Workshop-Sandbox>`_ was developed for classes and workshops, but is usable by anyone. This example generates the input files from provided observational data for the South Mountain Fan watershed near Phoenix. The entire example was designed to be ran entirely inside of a browser using cloud computing in a Github Codespace. Nonetheless, the repository can be downloaded and ran on a local machine like any of the other examples. The onyl difference being the simulation will need to be ran manually rather than using the code block inside of Run_Model.ipynb (only works in the cloud environment).

Benchmark Datasets
~~~~~~~~~~~~~~~~~~~~~

The :doc:`Benchmarks` repository, in addition to its primary role validating a tRIBS installation, can also serve as a worked example: it contains a point-scale model of a SNOTEL site and the Big Spring watershed model used in :doc:`QuickStart`. The examples contain all required inputs, already setup. Users only need to run the models.
